# 医院陪护床位与消毒交接系统

管理病区、陪护床、匿名申请人、使用时段、押金、床品/配件、消毒批次、维修与归还核验。
零第三方依赖，仅使用 Python 3 标准库（`http.server` + `sqlite3`）+ 原生前端。

> 演示数据全部匿名：申请人为“匿名患者·甲/乙…”，联系方式仅留脱敏尾号，不包含真实个人信息。

## 单条命令启动

```bash
./run.sh            # 首次自动生成申请、归还、隔离等样例并启动（默认 8000 端口）
./run.sh 8080       # 指定端口
./run.sh --reseed   # 清空并重新生成演示样例
```

等价于：

```bash
python3 -m app            # 自动建库 data/hospital.db、照片目录 data/photos/
```

打开 http://127.0.0.1:8000 ，右上角切换当前执行人（护士），不同护士归属不同病区，
跨病区操作会被拒绝。

## 六个交付视图

| 视图 | 内容 |
| --- | --- |
| 病区床位图 | 按病区分组；床位卡同时显示**清洁 / 占用 / 维修**三态与“禁约”角标；维修报修/完工 |
| 申请队列 | 待处理申请，按病区+规格筛选可分配床位，确认后锁定时段并冻结押金 |
| 使用时间线 | 开始使用 → 归还核验（含超时标记）→ 结算锁定；可发起归还核验/临时换床 |
| 归还核验 | **床架 / 床垫 / 床品 / 配件四列固定**，逐件登记归还数量与状态，异常项必填处理原因，可传交接照片 |
| 消毒批次 | 待消毒床位建批次；合格才恢复可约，失败继续阻断并登记异常 |
| 押金结算 | 冻结/扣减/退还/待退，异常可扣减后结算锁定；病区调拨（数量+责任人） |

## 核心业务规则

- **分配三阻断**：仅 `已清洁 + 非维修 + 无 active 订单` 的床位可预约；规格须与申请一致。
- **并发唯一**：`assignments` 上对 `status='active'` 建部分唯一索引，
  两名护士同时分配同一床位时只有一人成功（另一人返回 `bed_race`）。
- **清洁闭环**：归还后床位变 `dirty`（污染则 `isolated`），消毒批次**合格**后才恢复 `clean`；
  消毒失败维持阻断并写“消毒失败”异常。
- **维修锁定**：维修中床位不得预约；使用中床位须先临时换床才能报修。
- **临时换床**：限同病区同规格、目标床清洁空闲；原床转待清洁，记录原因与执行人。
- **配件数量**：逐件核对，归还数量不得超过应发数量；缺失/损坏/污染均需原因。
- **押金适配器**：进程内模拟，线程安全；所有动作带**幂等键**，并发/重试只入账一次。
- **结算锁定**：仅已归还订单可结算；结算后订单锁定，**迟到归还不能重开订单**。
- **病区权限**：护士仅能操作本病区的分配/归还/消毒；调拨只能由调出病区发起，
  必须登记数量（>0）与责任人，仅移动空闲、清洁、非维修床位。
- **六类异常**全部留痕：临时换床、押金差异、床品/配件缺失、污染隔离、使用超时、消毒失败。

## 数据与文件

- `data/hospital.db` —— SQLite 床位与消毒等全部记录（自动创建）。
- `data/photos/` —— 交接照片本地目录（归还照片、调拨照片；演示数据为程序生成的占位 PNG）。
- 押金由进程内模拟适配器处理，流水写入 `deposit_ledger`，汇总写入 `deposits`。

## 测试

覆盖要求的五项（并发竞争额外含多线程）：

```bash
python3 -m unittest tests.test_services -v
```

1. **床位竞争** —— 两线程两名护士抢同一床位，恰一成一败，活跃订单唯一。
2. **清洁阻断** —— dirty / 维修 / 隔离不可约；归还后阻断、消毒失败仍阻断、合格放行。
3. **配件数量** —— 超额归还拒绝；缺失汇总到配件列并带原因、登记异常；污染转隔离。
4. **押金幂等** —— 同键 hold/deduct/refund 并发重试只入账一次；结算后锁定不可重开。
5. **病区权限** —— 跨病区分配/归还/消毒/调拨拒绝；责任人、数量库存校验。

## 目录结构

```
app/
  db.py        SQLite 连接与 schema（含 active 部分唯一索引）
  deposit.py   进程内押金模拟适配器（线程锁 + 幂等键）
  services.py  领域服务：分配/归还/消毒/维修/换床/调拨/结算
  seed.py      匿名演示数据（申请、归还、隔离、超时、失败批次、维修、调拨）
  server.py    标准库 HTTP：JSON API + 静态文件 + 照片
  static/      index.html / styles.css / app.js（临床白 + 墨蓝 + 湖绿）
tests/
  test_services.py
run.sh         单条本地启动命令
```
